TerraVision Plugin Test Page

This page is used to test the development of the TerraVision Netscape plugin. You should see the plugin below and a number of controls that let you talk to the plugin via LiveConnect. This example shows a plugin rendering with native OpenGL that can be controlled via JavaScript on an HTML page and that can communicate with Java (illustrated here by output to the Java Console). The plugin can also detect various events such as mouse clicks.
