Coordinate conversion: Transform a point in Local Vertical coordinates to the Geocentric coordinate system

Documentation

Coordinate conversion: Transform a point in Local Vertical coordinates to the Geocentric coordinate system. The Local Vertical coordinate system (LVCS) is a localized, arbitrary coordinate space; points are represented by the tuple (x,y,z), with the Z axis oriented in the UP direction. Geocentric coordinates (GCC) are tuples that represent distances from the planet's center.
