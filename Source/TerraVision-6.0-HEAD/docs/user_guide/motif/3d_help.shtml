The 3-D Viewer "Help" Menu

The Help menu provides entries for retrieving helpful information about using TerraVision. This help information basically consists of selected pages from this User Guide displayed using Netscape. TerraVision will first look in the $MAGICHOME/etc/help directory for a local copy of the appropriate web page. If it cannot find this page, then it will use the permanent copy at the SRI web server, http://www.ai.sri.com/TerraVision/guide.

The following two entries can be found in the 3-D Viewer's Help menu:

  • Help on 3-D Viewer : displays the 3-D Viewer page from the TerraVision User Guide

  • Help on TerraVision : displays this first page of the TerraVision User Guide
