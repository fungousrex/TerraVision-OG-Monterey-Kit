TerraVisionTM 5.1 - X/Motif Version

The X/Motif version of TerraVision runs under the IRIX 6.5 platform and uses the native X interface for its GUI. Development on this user interface has been frozen in preference for the Tcl/Tk version.
"File" Menu - Opening datasets, Debuging, and Dataset Info.
"Views" Menu - 2D, 3D, and Map Viewers
"Logging" Menu - Logging diagnostic information
"Prefs" Menu - DPSS Preferences
"Help" Menu - About, License, Overview, etc.
