The "Logging" Menu

The logging facilities of TerraVisionTM are useful for tracing the state of the application and the network over which the terrain data are being fetched. We use the NetLogger tools from LBNL to implement our logging facility. For further information about NetLogger, please refer to the NetLogger Home Page.

Start Logging

Selecting this option will initiate logging of TerraVisionTM events. This will cause log events to be sent to the ouput specified by the "Set Logging Options" window, and will also allow you to view data in the "View Logging Graphs" window. Once you have selected this option, it will ghost so that you cannot select it again until you select the "Stop Logging" option.

Stop Logging

Ceases logging, flushes all events out to their destination, and closes any currently open log files. If you select "Start Logging" again, then any local disk log files will be overwritten with the new event log.

View Logging Graphs

Set Logging Options

This window lets you specify where the log data are set to. NetLogger allows you to send log events to one of: a file on local disk, a port on a host, or to the syslog. The default option is to send log events to a log file on local disk. In this case, you can specify the directory to which the log files are written via the Log Directory text field (this defaults to "/usr/tmp").

When logging to local disk, TerraVisionTM will create a single log file for each of the OI and DEM datasets that are being browsed. In addition, separate log files are created for the DPSS activities of each of these datasets, if these reside on a DPSS. The log files following the naming convention: "tvlog-<datasetname>[.dpss]", e.g. tvlog-yosemite.oi or tvlog-yosemite.oi.dpss.

Set Log Events

This sub-menu lets you specify which events you wish to record log events for when logging is active. You can then select the individual areas of the application that you wish to log by selecting or deselecting the appropriate Log xxx entry. By default, the system will log all areas of application.

Clean Log Directory

When you select Log To File from the Set Logging Output menu option, all log files will be written to the specified directory on local disk. These files are not removed automatically as it is possible that the user may wish to visualize these after the current TerraVisionTM session. You can therefore use this menu option to explicitly delete all TerraVisionTM log files (tvlog-*) that exist in the currently specified Log Directory.
